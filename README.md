## 🚀 Installation

Clone this repository.

```bash
git clone https://github.com/faishalkc/Portfolio.git
```

Go into the project directory.

```bash
cd Portfolio
```

Install dependencies.

```bash
npm install
```

Start the development server.

```bash
npm run dev
```

Build for production.

```bash
npm run build
```

Preview the production build.

```bash
npm run preview
```
